=======================================
 Digital Ocean Deployment Guide
 FastAPI + Streamlit + PostgreSQL + MongoDB
=======================================

PREREQUISITES
- Digital Ocean account
- SSH key added to your DO account
- OpenAI API key from platform.openai.com

=======================================
STEP 1: Create a Droplet
=======================================
- Go to Digital Ocean -> Create Droplet
- Image: Ubuntu 24.04
- Plan: Basic $12/mo (2GB RAM, 1 vCPU)
- Auth: SSH key (recommended)
- Note the IP address after creation

=======================================
STEP 2: SSH into the Droplet
=======================================
  ssh root@<YOUR_DROPLET_IP>

=======================================
STEP 3: Clone and Run Setup Script
=======================================
  cd /opt
  git clone https://github.com/prasadvenkat22/fastapi.git
  cd fastapi
  bash setup-server.sh

=======================================
STEP 4: Setup Script Prompts
=======================================
The script will ask for:

  Prompt                   What to Enter
  ----------------------   ------------------------------------------
  PostgreSQL password      Any strong password (creates the DB with it)
  pgAdmin password         Any password (only for debug mode)
  OpenAI API Key           Your key starting with sk-proj-...
  Domain                   Your domain, or press Enter to use the IP
  Start now?               y

IMPORTANT: Do NOT use quotes around any values.

=======================================
STEP 5: Verify Deployment
=======================================
  ./deploy.sh health

All 4 checks should show OK:
  - FastAPI: OK
  - Streamlit: OK
  - PostgreSQL: OK
  - MongoDB: OK

=======================================
STEP 6: Access Your App
=======================================
  Streamlit:    http://<DROPLET_IP>:8501
  FastAPI docs: http://<DROPLET_IP>:8000/docs
  Via nginx:    http://<DROPLET_IP> (port 80)

=======================================
DEPLOY MANAGEMENT COMMANDS
=======================================
  ./deploy.sh start      Start all production services
  ./deploy.sh stop       Stop all services
  ./deploy.sh restart    Restart all services
  ./deploy.sh update     Pull latest code, rebuild, and restart
  ./deploy.sh logs       Show logs (follow mode)
  ./deploy.sh status     Show container status and memory usage
  ./deploy.sh stats      Show live resource usage
  ./deploy.sh health     Run health checks on all services
  ./deploy.sh debug      Start with pgAdmin enabled (port 5050)

=======================================
UPDATING CODE ON SERVER
=======================================
After pushing changes to GitHub:

  ssh root@<DROPLET_IP>
  cd /opt/fastapi
  ./deploy.sh update

=======================================
RUNNING LOCALLY
=======================================
  docker compose up -d --build

Access locally:
  Streamlit:    http://localhost:8501
  FastAPI docs: http://localhost:8000/docs
  pgAdmin:      http://localhost:5050
  Nginx:        http://localhost (port 80)

=======================================
ENV FILE RULES
=======================================
- .env is for local development
- .env.production is for the server (generated by setup-server.sh)
- NEVER use quotes around values in either file
- NEVER commit .env or .env.production to git (they contain secrets)
- .env.production.example is the safe template checked into git

=======================================
TROUBLESHOOTING
=======================================
Problem: "env file .env not found"
  Fix: ln -s .env.production .env

Problem: Container keeps restarting
  Fix: docker compose logs <service> --tail 50

Problem: OpenAI API key error
  Fix: Edit .env.production, fix the OPENAI_API_KEY line (no quotes),
       then ./deploy.sh restart

Problem: Out of memory
  Fix: Use docker-compose.prod.yml (deploy.sh uses it automatically)
       which limits memory per container for 2GB droplets
