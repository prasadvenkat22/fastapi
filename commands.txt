TRADING SETTINGS -- COMMANDS FOR THE DIGITALOCEAN DROPLET
=========================================================

Stop loss, stall, give-back, budgets and the other exit/entry knobs can be
changed WITHOUT editing .env.production and WITHOUT recreating the app
container. Changes go to /opt/fastapi/trading_overrides.env and the next cron
cycle (within a minute) trades on them.

Same file as the web page:  https://dataaisys.com/desk/settings  (admin to save)

Precedence:  trading_overrides.env  >  .env.production  >  code default
Remove an override and the .env.production value is back next cycle.

Only whitelisted keys are accepted (list them with `list` below). Going live
(TRADING_DTE0_LIVE, TRADING_MANAGE_ORPHANS) is NOT here -- that stays an
.env.production edit. The kill switch is the runtime off switch.


0. ONE-TIME: log in and set up a shortcut
-----------------------------------------
ssh root@159.223.127.31
cd /opt/fastapi

# paste this once per ssh session (or add it to ~/.bashrc):
alias tset='docker compose -f /opt/fastapi/docker-compose.yml -f /opt/fastapi/docker-compose.prod.yml --project-directory /opt/fastapi exec -T -w /app -e PYTHONPATH=/app app python scripts/settings.py'


1. SEE WHAT IS IN FORCE
-----------------------
tset list                    # every knob: * = override, blank = .env.production, . = code default
tset list --group engine     # the QQQ engine's own stall (morning debit + credit)
tset list --group 0dte       # only the 0DTE exits
tset list --group weekly     # only the weekly (later-expiry) exits
tset list --group entries    # budgets, rotations, entry bands
tset get TRADING_ORPHAN_STOP_PCT     # one knob: bounds, default, env value, override


2. CHANGE SETTINGS (several at once is fine; a bad value changes nothing)
--------------------------------------------------------------------------

# --- Trade buckets: NEW entries on/off (all OFF by default) ---
tset set TRADING_BUCKET_QQQ_0DTE=true         # engine's QQQ same-day entries
tset set TRADING_BUCKET_STOCK_0DTE=true       # single-stock 0DTE rotation
tset set TRADING_BUCKET_STOCK_W3=true         # single-stock 3-day (weekly runs buying 2-4 days out, Mon-Wed)
tset set TRADING_BUCKET_STOCK_W7=true         # single-stock 7-day (weekly runs buying 5+ days out, Thu-Fri)
tset set TRADING_POSITION_BUDGET=450 TRADING_DTE0_MAX_BUDGET=450 TRADING_W3_MAX_BUDGET=450 TRADING_W7_MAX_BUDGET=400   # per-bucket budgets ($)
# (TRADING_BUCKET_STOCK_WEEKLY and TRADING_WEEKLY_MAX_BUDGET were retired 09-26, section 245)
# Entries per day, per bucket (0 = no cap)                              -- section 250
tset set TRADING_MAX_ENTRIES_QQQ_0DTE=2 TRADING_MAX_ENTRIES_STOCK_0DTE=2 TRADING_MAX_ENTRIES_STOCK_W3=1 TRADING_MAX_ENTRIES_STOCK_W7=1

# --- The settings page: four identical cards (section 261) ---
# Each book: On/off, Budget, Entries per day, Bollinger band, Stop loss,
# Stop confirmation, Take profit. Plus an "All books" card and Advanced.
# QQQ engine: its ONLY entry is the 1-minute Bollinger band touch.
tset set TRADING_BAND_TOUCH_PERIOD=20 TRADING_BAND_TOUCH_SD=2 TRADING_BAND_TOUCH_START=09:45 TRADING_BAND_TOUCH_END=15:00
tset set TRADING_ENGINE_STOP_PCT=-20 TRADING_STOP_CONFIRM_MINUTES=1 TRADING_ENGINE_TAKE_PROFIT_PCT=25
# Stock books: Bollinger band picks the direction (lower -> calls only,
# upper -> puts only, inside -> no trade). 0DTE 5-min bars, 3/7-day hourly.
tset set TRADING_BOLLINGER_GATE_DTE0=true TRADING_BOLLINGER_GATE_W3=true TRADING_BOLLINGER_GATE_W7=true
# Trades per run (the Entry schedule panel's column; blank = the cron's 4/3/3):
tset set TRADING_MAX_TRADES_STOCK_0DTE=2 TRADING_MAX_TRADES_STOCK_W3=2 TRADING_MAX_TRADES_STOCK_W7=2
# QQQ: the 20-SMA exit books only once the spread is up this much (0 = any):
tset set TRADING_BAND_TOUCH_MIN_PROFIT_PCT=10
# QQQ waits after a WIN before the next entry (.env.production sets 30 min):
tset set TRADING_WIN_COOLDOWN_MINUTES=0
# All books:
tset set TRADING_MAX_DAILY_LOSS_PCT=0.06            # QQQ engine stops entering after losing 6% of the day's starting equity
tset set TRADING_ORPHAN_FORCE_CLOSE=15:45           # also the engine's force close
# Retired 10-05 with the old QQQ rules: TRADING_BAND_TOUCH, TRADING_BAND_ONLY,
# TRADING_*_ENTRIES, TRADING_MORNING_*TIERS, TRADING_STALL_*, TRADING_CREDIT_STALL_*,
# TRADING_MORNING_PUT_CLOSE_BY. tset refuses them; delete stale lines by hand.

# --- Orders at the mid                                                  -- section 253 ---
# Entries (QQQ engine and stock books) rest at the mid only and are skipped if
# unfilled; QQQ profit exits work from the mid; stops always go at the natural.
tset set TRADING_MID_ORDERS=true
tset set TRADING_MID_ENTRY_MAX_STEPS=0 TRADING_MID_ENTRY_WAIT_SECONDS=20      # 0 = never chase the ask
tset set TRADING_MID_STEP=0.02 TRADING_MID_STEP_SECONDS=6 TRADING_MID_MAX_STEPS=3 TRADING_MID_BUDGET_SECONDS=25

# --- 0DTE stop loss (applies to positions expiring TODAY only) ---
# These rows also manage MANUAL QQQ 0DTE trades (and the stock 0DTE book).
# They are the first rows of "0DTE exits" on /desk/settings (section 256).
# TRADING_ORPHAN_TAKE_PROFIT ("legacy") was never read and is gone from the
# page; the profit target is TRADING_ORPHAN_TARGET_RETURN_PCT.
tset set TRADING_ORPHAN_STOP_PCT=-20                  # stop at -20% of cost   (range -100..0)
tset set TRADING_ORPHAN_STOP_CONFIRM_MINUTES=5        # must hold 5 min (0 = first check)
tset set TRADING_ORPHAN_STOP_RESPECTS_INTRINSIC=false # false = plain stop on price (no break-even hold-off)
tset set TRADING_ORPHAN_OTM_STOP=true                 # close the moment a debit spread is OTM
tset set TRADING_ORPHAN_SLOW_STOP_PCT=-15 TRADING_ORPHAN_SLOW_STOP_MINUTES=30

# --- 0DTE stall (close a winner that stops making new highs) ---
tset set TRADING_ORPHAN_STALL_MINUTES=20              # minutes without a new peak (0 = off)
tset set TRADING_ORPHAN_STALL_GIVEBACK_PCT=10         # give-back in return points
tset set TRADING_ORPHAN_STALL_GIVEBACK_BAND=0.20      # OR as share of (width - entry); wins when > 0
tset set TRADING_ORPHAN_STALL_MIN_GAIN_PCT=8          # only exit if it books at least +8%

# --- 0DTE targets and times ---
tset set TRADING_ORPHAN_TARGET_RETURN_PCT=30          # take profit at +30% on cost
tset set TRADING_ORPHAN_CEILING=0.90                  # or at 90% of width
tset set TRADING_ORPHAN_FORCE_CLOSE=15:45             # flatten same-day positions (ET)
tset set TRADING_ORPHAN_HOLD_UNTIL=09:35              # no loss-taking before (ET)

# --- 0DTE resting sell limit ("ask mode"): auto-managed, follows the underlying ---
# Rests a sell at START x width on a pinned spread; holds while the underlying
# is at/above session VWAP, steps down STEP every STEP_MINUTES while below,
# never under FLOOR; stops and the flatten stay live and cancel it to act.
tset set TRADING_ORPHAN_ASK=true TRADING_ORPHAN_ASK_START_WIDTH=0.90
tset set TRADING_ORPHAN_ASK_FLOOR_WIDTH=0.80           # floor 80% of width (0 = entry x (1+target))
# Short-strike guard: close when the underlying is through the SHORT strike
# under an adverse VWAP for N continuous minutes (resets on a bounce).
tset set TRADING_ORPHAN_STRIKE_GUARD=true TRADING_ORPHAN_STRIKE_GUARD_MINUTES=3
tset set TRADING_ORPHAN_STRIKE_GUARD_BUFFER=0          # points past the strike before the clock starts
# Profit lock: once the spread's MARK reaches cost + X of width, sell if it
# falls back there (0.10 on a 10-wide @ 6.33 = 7.33). Losses: the -10% stop.
tset set TRADING_ORPHAN_PROFIT_LOCK_WIDTH=0.10
# Underlying stop: close when the UNDERLYING is past break-even (+cushion)
# under an adverse VWAP for N minutes -- judged on MU, not the spread's mark.
tset set TRADING_ORPHAN_UNDER_STOP=true TRADING_ORPHAN_UNDER_STOP_MINUTES=2
tset set TRADING_ORPHAN_UNDER_STOP_CUSHION=0            # points above break-even (calls)
tset set TRADING_ORPHAN_UNDER_STOP_CUSHION_WIDTH=0.20     # OR as a share of width; the larger applies
tset set TRADING_ORPHAN_UNDER_STOP_ARM_FIRST=true        # watch only once MU has been above the line
tset set TRADING_ORPHAN_PREARM_STOP_PCT=0                # mark stop until armed (0 = ordinary -10%)
# DO NOT also place a manual limit on the same legs: a working order the
# engine did not place switches off its stop, ask and 15:45 flatten
# (logged every cycle as "an order this engine did not place is working").

# --- Weekly (later-expiry) ladder ---
tset set TRADING_ORPHAN_LATER_STOP_PCT=-20 TRADING_ORPHAN_LATER_STOP_MINUTES=2   # 2+ sessions left
tset set TRADING_ORPHAN_LATER_SCALE_DAYS=2             # step: full-week values until the last day
tset set TRADING_ORPHAN_LATER_STOP_PCT_1D=-10 TRADING_ORPHAN_LATER_STOP_MINUTES_1D=2   # keep scaling from widening it
tset set TRADING_ORPHAN_LATER_STALL_ARM=25            # stall arms once gain reaches +25%
tset set TRADING_ORPHAN_LATER_STALL_MINUTES=30        # then fires after 30 min without a new peak
tset set TRADING_ORPHAN_LATER_STALL_GIVEBACK_ATR=0.25 # give-back in ATR (replaces points when > 0)
tset set TRADING_ORPHAN_LATER_HOLD_UNTIL=09:45
tset set TRADING_ORPHAN_LATER_STOP_PCT_1D=-30         # scaled stop the day before expiry

# --- Account circuit breaker ---
tset set TRADING_ACCOUNT_FLOOR=12000                  # flatten EVERYTHING below $12,000 equity (0 = off)

# --- Entries and budgets ---
tset set TRADING_DTE0_ROTATE_CUTOFF=11:30 TRADING_DTE0_MAX_ROTATIONS=3
tset set TRADING_DTE0_ROTATE_COOLDOWN_MIN=30
tset set TRADING_WEEKLY_MIN_PWIN=0.45
tset set TRADING_PICK_MIN_SHORT_PAYS_PCT=10            # short-leg bid >= 10% of long ask, both books (0 = off)

(The numbers above are examples of the syntax, not recommendations. Check
`tset list` first -- several of these are already set in .env.production.)


3. UNDO
-------
tset unset TRADING_ORPHAN_STOP_PCT        # back to the .env.production value
tset reset                                # drop EVERY override
tset log                                  # who changed what, when (UTC)


4. CONFIRM THE CYCLE PICKED IT UP
---------------------------------
cat /opt/fastapi/trading_overrides.env            # the file itself
tail -f /var/log/qqq-trading.log                  # next minute's cycle
# a hand-edited bad line shows up in that log as:
#   [trading_overrides] line N: ... -- ignored


5. NOTES
--------
* Takes effect on the next cron minute for decisions. The rule columns on
  the Positions page come from the API process and show the new values only
  after the next app recreate:
    docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --force-recreate app
  That recreate costs ~1 minute of cycles; time it against open 0DTE positions.
* A change applies to positions ALREADY open, not just new ones. Tightening
  a stop can close a position on the very next cycle.
* trading_overrides.env and trading_overrides.log are gitignored: `git pull`
  never touches them.
* The permanent home for a setting is still .env.production. To make an
  override permanent: add it there (back up first as
  .env.production.bak-<tag>), then `tset unset KEY`.

7. THE ENGINE AND THE JOBS: IS IT RUNNING, START, STOP, AFTER A REBOOT
----------------------------------------------------------------------
# WHAT RUNS TRADING: the droplet's CRONTAB. `scripts/run_cycle.py` every minute
# is the engine (QQQ entries AND every exit: stop, stall, flatten, for all
# positions). The rotations and data jobs are further crontab lines. Nothing
# needs "starting" on a normal day: cron runs them on schedule, weekdays only,
# and skips outside market hours / holidays by itself.
#
# DO NOT press "Start scheduler" on the desk Controls page. That is an older
# in-app loop doing the SAME job as the cron line; with both, every cycle runs
# twice at once (the 09-03 split order). It is refused unless
# TRADING_ALLOW_APP_SCHEDULER=true, which is only for a box with no cron line.

# --- 7a. Is it running? ---
systemctl is-active cron                       # active
crontab -l | grep -c run_cycle.py              # 1 (the engine line)
tail -n 5 /var/log/qqq-trading.log             # a "cycle ok" or "skipped -- ..." line every minute
docker ps --format '{{.Names}} {{.Status}}'    # app, postgres_container, nginx, data-ai-web all Up
# The Entry schedule panel on /desk/settings shows the rotation lines (read-only).

# --- 7b. After a reboot / if something is down ---
# cron is enabled at boot and every container is restart: always, so a reboot
# needs nothing. If a check above fails:
systemctl enable --now cron
cd /opt/fastapi && docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d
cd /opt/data-ai-solutions && docker compose -f docker-compose.server.yml up -d

# --- 7c. A job is missing from the crontab: put it back ---
crontab -l > /root/crontab.bak-$(date +%Y%m%d%H%M)     # ALWAYS back up first
./scripts/install_cron.sh                              # re-adds the engine line (run_cycle.py) only
# Any other line: append it, dropping exact duplicates, then check:
#   ( crontab -l; echo '<the line below>' ) | awk '!seen[$0]++' | crontab -
#   crontab -l | grep -c '<script name>'
# The trading lines as installed (times are UTC; ET = UTC-4 until Nov 1, then -5):
#   * * * * *          run_cycle.py                          engine + all exits      /var/log/qqq-trading.log
#   */5 13-18 * * 1-5  dte0_trade.py --rotate --live --budget 5000 --max-trades 4
#                                                            single-stock 0DTE       /var/log/dte0-trade.log
#   50 13,17 * * 1-3   dte0_trade.py --book weekly --rotate --live --budget 5000 --max-trades 3
#                      --expiry friday --symbols AMZN,AVGO,CRWV,DELL,GOOGL,META,MRVL,MSFT,MU,NVDA,PANW,SNDK,STX,WDC,INTC,TSLA,AAPL,AMD
#                                                            3-day weekly            /var/log/weekly-trade.log
#   50 13,17 * * 4-5   (same, --expiry +5)                   7-day weekly            /var/log/weekly-trade.log
#   */10 * * * *       crontab -l > /opt/fastapi/crontab.snapshot   feeds the Entry schedule panel
# Every python line is prefixed with:
#   cd /opt/fastapi && docker compose -f /opt/fastapi/docker-compose.yml -f /opt/fastapi/docker-compose.prod.yml
#   --project-directory /opt/fastapi exec -T -w /app -e PYTHONPATH=/app app python scripts/<script> ...
# (-w /app and PYTHONPATH are required, or the job dies every run on
#  "No module named 'config'" while cron reports nothing wrong.)
# Data jobs also in the crontab: capture_chain, news_watch, news_hourly,
# news_enrich, macro_objective, macro_outcome, verdict_outcome, profit_stall,
# dte0_shadow (--open/--mark/--settle), issue_cert.sh. price_alert.py is
# commented out (09-26). `crontab -l` is the authority.

# --- 7d. Stop / pause trading: pick the right tool ---
# STOP NEW ENTRIES, keep managing open positions  <- the normal choice
tset set TRADING_BUCKET_QQQ_0DTE=false TRADING_BUCKET_STOCK_0DTE=false TRADING_BUCKET_STOCK_W3=false TRADING_BUCKET_STOCK_W7=false
#   (or the Trade buckets switches on /desk/settings). Stops, stall and the
#   15:45 flatten keep running on everything open. Undo: set them back to true.
#
# KILL SWITCH -- halts the ENGINE ENTIRELY, INCLUDING EXITS:
# (that includes the orphan ladder that stops/books MANUAL trades -- with the
#  switch on, a hand-placed spread has NO automatic stop or target)
ls -la /opt/fastapi/KILL_SWITCH.txt           # is it on?
touch /opt/fastapi/KILL_SWITCH.txt            # on   (or Controls page -> kill switch)
rm /opt/fastapi/KILL_SWITCH.txt               # off
#   CAUTION (09-28): run_cycle.py then skips the whole cycle, so open
#   positions get NO stop, stall or flatten while it is on. And the stock
#   rotation (dte0_trade.py) does NOT check it: it keeps opening trades unless
#   its bucket switches are off. Use it only when flat, together with the
#   bucket switches.
#
# REMOVE A JOB completely: comment its line (back up first), e.g.
#   crontab -l | sed '/dte0_trade.py --rotate --live/ s/^/# /' | crontab -

# --- 7e. Run a job once by hand ---
# Engine cycle now (respects market hours and the kill switch):
docker compose -f docker-compose.yml -f docker-compose.prod.yml exec -T -w /app -e PYTHONPATH=/app app python scripts/run_cycle.py
# Rotation DRY RUN (no --live: screens and logs, never sends an order):
docker compose -f docker-compose.yml -f docker-compose.prod.yml exec -T -w /app -e PYTHONPATH=/app app python scripts/dte0_trade.py --max-trades 3 --symbols MU,NVDA,TSLA
docker compose -f docker-compose.yml -f docker-compose.prod.yml exec -T -w /app -e PYTHONPATH=/app app python scripts/dte0_trade.py --book weekly --expiry +5 --max-trades 3 --symbols MU,NVDA,TSLA
#   A dry run ends with the plan, or "Nothing cleared ..." and the rejections
#   grouped by reason. It is the fastest way to see why a book is not buying.

# --- 7f. Logs ---
tail -f /var/log/qqq-trading.log        # engine + exits, every minute
tail -f /var/log/dte0-trade.log         # single-stock 0DTE rotation
tail -f /var/log/weekly-trade.log       # 3-day / 7-day rotation
tail -n 20 /opt/fastapi/trading_overrides.log    # settings changes (who, what, when)
