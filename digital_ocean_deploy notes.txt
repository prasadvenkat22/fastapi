
Deploy to a New Droplet — Step by Step
Last updated: 2026-04-05 | Server: 142.93.177.153 | Domain: dataiqsystems.com

  1. Create the Droplet
  - Digital Ocean → Create Droplet
  - Image: Ubuntu 24.04
  - Plan: Basic $12/mo (2GB RAM, 1 vCPU)
  - Auth: SSH key (recommended) or password
  - Note the IP address after creation

  2. SSH into the Droplet

  ssh root@<YOUR_DROPLET_IP>

  3. Download and Run Setup Script

  cd /opt
  git clone https://github.com/prasadvenkat22/fastapi.git
  cd fastapi
  bash setup-server.sh

  4. The Script Will Prompt You For:
  ┌─────────────────────┬──────────────────────────────────────────────────────────────────────────┐
  │       Prompt        │                              What to Enter                               │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ PostgreSQL password │ Any strong password you choose (e.g. MyStr0ngP@ss) — this creates the DB │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ pgAdmin password    │ Any password (only used if you enable debug mode)                        │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ OpenAI API Key      │ Your key starting with sk-proj-... from platform.openai.com              │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ Domain              │ Your domain, or just press Enter to use the droplet IP                   │
  ├─────────────────────┼──────────────────────────────────────────────────────────────────────────┤
  │ Start now?          │ y                                                                        │
  └─────────────────────┴──────────────────────────────────────────────────────────────────────────┘

  5. Run Alembic Migrations (required after first deploy or schema changes)

  docker exec app bash -c "alembic upgrade head"

  Run this any time new columns or tables are added (e.g. image_url columns, Product table).

  6. Verify

  ./deploy.sh health

  All 3 checks (FastAPI, PostgreSQL, MongoDB) should show OK.

  7. Access Your App

  - FastAPI docs:   https://dataiqsystems.com/docs
  - API base:       https://dataiqsystems.com/CRUD/
  - Image uploads:  https://dataiqsystems.com/images/
  - Static files:   https://dataiqsystems.com/static/
  - pgAdmin:        http://142.93.177.153:5050  (dev only — disabled in prod by default)

  ---
  Routine Deploy (update existing server with latest code)

  ssh root@142.93.177.153
  cd /opt/fastapi
  git pull origin main
  docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d --build app
  docker exec app bash -c "alembic upgrade head"   # only needed if models changed

  ---
  Useful Commands After Deploy

  ./deploy.sh status    # check containers
  ./deploy.sh logs      # view logs
  ./deploy.sh update    # pull latest code & rebuild
  ./deploy.sh restart   # restart everything
  ./deploy.sh health    # run health checks

  docker logs app --tail 50              # FastAPI app logs
  docker exec app bash -c "alembic current"   # check migration state
  docker exec app bash -c "alembic upgrade head"  # apply pending migrations

  ---
  Nginx Config Notes

  Two nginx config files are mounted from ./app/nginx/conf.d/ into the nginx container:
  - default.conf        — HTTP (port 80) catch-all, proxies all API routes to app:8000
  - dataiqsystems.conf  — HTTPS (port 443) for dataiqsystems.com with SSL cert

  Both files must have matching location blocks. Current proxied routes:
    /CRUD/          → FastAPI CRUD endpoints
    /api/           → FastAPI API endpoints
    /FileUploads/   → CSV/file upload endpoints
    /images/        → Image upload/retrieve/delete (added 2026-04-05)
    /static/        → Uploaded image files served by FastAPI (added 2026-04-05)
    /docs           → FastAPI Swagger UI
    /openapi.json   → OpenAPI schema
    /redoc          → ReDoc UI
    /               → Next.js frontend (data-ai-solutions-web-1:3000)

  After editing nginx config files, restart nginx:
  docker compose -f docker-compose.yml -f docker-compose.prod.yml restart nginx

  ---
  Database Schema Changes

  Alembic is configured with autogenerate. To create a migration after model changes:

  docker exec app bash -c "alembic revision --autogenerate -m 'describe change'"
  docker exec app bash -c "alembic upgrade head"

  Migrations are stored in alembic/versions/ and committed to git.
